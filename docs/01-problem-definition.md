# 나비 문제정의

- 작성일: 2026-11-05
- 범위: 웹 서비스만 다룬다. 모바일 앱은 만들지 않는다.
- 레퍼런스: 치지직 화면 캡처 67장(`reference/` 폴더). 이 중 10장을 직접 확인했고, 나머지는 파일 이름으로 분류했다.

## 1. 한 줄 요약

나비는 방송 장비가 없는 사람이 브라우저에서 바로 방송을 켜고 끌 수 있게 하는 실시간 방송 서비스다. 가장 먼저 푸는 문제는 방송을 켜기까지의 준비 단계가 길다는 점이다.

## 2. 핵심 문제

방송 장비가 없는 사람은 지금 보고 있는 화면이나 카메라를 바로 공개로 보여주고 싶어 한다. 하지만 기존 방송 플랫폼에서는 외부 송출 프로그램을 설치하고 스트림 키를 설정해야 방송을 시작할 수 있다. 이 준비 단계가 길어서 보여주고 싶은 순간이 방송으로 이어지지 않는다.

### 근거 (레퍼런스에서 확인한 사실)

- 치지직 스튜디오의 방송하기 화면에는 "방송 시작 및 종료는 스트리밍 소프트웨어에서 가능합니다"라고 나온다. 치지직 안에는 방송 시작 버튼이 없다.
- 스트림 설정 화면에서 방송 프로그램이 영상을 보낼 서버 주소(RTMP 주소)와 스트림 키를 복사해야 한다. 복사한 값은 OBS나 PRISM 같은 프로그램에 붙여 넣는다.
- 스튜디오 메뉴에 OBS 가이드와 PRISM 가이드가 따로 있다. 설정이 어렵다는 뜻으로 해석했다.
- 레퍼런스의 모바일 캡처에는 방송을 켜는 화면이 없다. 실제로 기능이 없는지, 캡처에서 빠졌는지는 확인하지 못했다.

## 3. 대상 사용자

두 사용자 모두 핵심 대상이다.

| 사용자 | 상황 | 원하는 것 |
|---|---|---|
| 가볍게 한 번 보여주는 사람 | 친구에게 게임 화면을 보여주거나 현장을 중계하고 싶다 | 링크를 보내고 바로 켜고, 끝나면 확실하게 끈다 |
| 입문 스트리머 | 방송을 꾸준히 해 보고 싶지만 장비 세팅이 부담된다 | 설치 없이 시작하고, 방송이 끝나면 기록과 반응과 수익이 남는다 |
| 시청자 | 링크나 방송 목록으로 들어온다 | 가입 없이 바로 본다. 댓글이나 후원을 할 때만 로그인한다 |

두 방송자는 같은 사람의 다른 시점일 수 있다. 가볍게 한 번 켠 방송에 댓글과 후원이 달리고 다시보기로 남으면, 그 사람은 다음에 또 켤 이유가 생긴다. 그렇게 다시 켜는 사람이 입문 스트리머가 된다.

## 4. 서비스 흐름

1. 방송자가 브라우저에서 바로 방송을 켠다.
2. 시청자가 링크나 목록으로 들어와서 본다.
3. 댓글, 후원, 구독, 다시보기가 남는다.
4. 방송자가 돈과 반응을 얻고 다시 켠다. 이렇게 입문 스트리머가 된다.
5. 방송과 시청자가 늘어나면 나비의 수수료 수익과 광고 수익이 늘어난다.

## 5. 켜기까지의 단계 비교

| 단계 | 치지직 | 나비 |
|---|---|---|
| 송출 프로그램 설치 | 필요하다 | 없앤다 (브라우저에서 송출) |
| 스트림 주소와 키 복사, 붙여넣기 | 필요하다 | 없앤다 |
| 회원가입과 로그인 | 필요하다 | 남는다 (공모 요구사항) |
| 방송 제목 등 정보 입력 | 필요하다 | 남는다 (공모 요구사항). 입력 항목은 줄일 수 있다 |
| 브라우저의 화면·카메라·마이크 권한 허용 | 프로그램이 처리한다 | 새로 생긴다 |
| 탭 공유 시 "탭 오디오 공유" 체크 | 없다 | 새로 생긴다 (맥 크롬 기준) |

브라우저 송출로 큰 단계 두 개가 사라진다. 대신 작은 단계 두 개가 새로 생긴다. 새로 생긴 단계에서 사용자가 막히면 핵심 문제를 풀지 못한 것과 같다. 그래서 이 두 단계도 핵심 문제의 범위에 포함한다.

시청자에게도 같은 문제가 있다. 링크로 처음 들어온 순간에 광고가 나오면 시청자는 바로 볼 수 없다. 아이폰에서 소리가 꺼진 채 재생되는 경우도 마찬가지다.

## 6. 함께 다룰 문제

| 문제 | 내용 | 다루는 방식 |
|---|---|---|
| 방송 상태가 분명해야 한다 | 송출이 끊겨도 목록에 '방송 중'이 남거나, 종료했는데 송출이 계속되면 사용자가 믿고 쓸 수 없다. 치지직 리허설 화면에도 "송출이 끊겨도 자동으로 종료되지 않는다"는 안내가 있다 | 핵심 문제와 함께 지킬 조건이다. 서버가 방송 정보와 실제 송출 연결을 하나로 묶어 관리한다 |
| 끝난 방송에 남는 것이 있어야 한다 | 수익, 반응, 기록이 남지 않으면 다시 켤 이유가 없다 | 다음 과제다. 댓글, 후원, 녹화와 다시보기 기능이 맡는다 |
| 작은 방송이 발견되어야 한다 | 치지직 홈은 시청자가 많은 방송을 위에 크게 보여준다. 시청자가 0명인 방송은 보이지 않는다. 시청자가 없으면 후원, 구독, 광고 수익이 모두 생기지 않는다 | 수익 단계의 과제다. 이번 개발 범위에서는 위험으로 기록만 한다 |

## 7. 수익 구조

| 수익 | 돈을 내는 사람 | 방식 |
|---|---|---|
| 후원 수수료 | 시청자 | 시청자가 방송자에게 후원한다. 방송자가 대부분을 받고, 나비는 일부를 수수료로 받는다 |
| 채널 구독 | 시청자 | 특정 방송자를 구독하면 그 채널에서 광고가 나오지 않는다. 방송자가 대부분을 받고, 나비는 일부를 수수료로 받는다 |
| 플랫폼 구독 | 시청자 | 나비 전체를 구독하면 모든 방송에서 광고가 나오지 않는다 |
| 광고 | 광고주 | 방송에 들어갈 때 가끔 무작위로 광고를 보여준다. 5초 뒤에 건너뛸 수 있다. 처음 들어온 시청자에게는 보여주지 않는다(06 결정 32) |

방송자가 더 많이 벌수록 나비의 수수료도 늘어난다. 그래서 방송자와 나비의 이익이 같은 방향을 본다.

### 수익 구조에서 확인할 점

- 네 가지 수익이 모두 시청자에게서 나온다. 시청자가 다시 오는 이유는 팔로우한 방송자가 방송을 켜면 알려 주는 방향으로 정했다. 이 기능은 이번 개발 범위에 넣지 않는다(06 결정 4).
- 광고가 너무 드물면 광고를 없애려고 구독할 이유가 약해진다. 광고가 너무 잦으면 "바로 본다"는 약속이 깨진다. 그래서 같은 시청자에게는 30분에 1번, 하루 6번까지만 보여주기로 했다. 이 숫자는 임시다(06 결정 32).
- 플랫폼 구독자에게는 채널 구독의 광고 제거 혜택이 의미가 없다. 채널 구독에는 "이 방송자를 응원한다"는 다른 이유가 필요하다. 치지직은 구독 개월 수 표시, 재구독, 구독권 선물을 제공한다.
- 초기에는 시청자가 적어서 광고 수익이 작다. 초기 수익은 대부분 후원 수수료에서 나올 것으로 추론한다.

## 8. 개발 범위

- 공모 마감: 2026년 11월 19일(목) 밤 11시 59분
- 개발 인원: 1명이 기획, 디자인, 개발을 모두 맡는다.
- 포함: 필수 기능 전부(PC 방송, 모바일 웹 방송, 방송 관리와 시청, 인증과 권한), 선택 기능 전부(댓글, 후원, 녹화와 다시보기)
- 제외: 모바일 앱, 광고, 채널 구독, 플랫폼 구독. 광고와 구독은 이 문서에서 수익 구조로만 설명한다. 홈에는 실제 광고 대신 "광고 예시" 배너를 두어 광고가 들어갈 자리만 보여준다(06 결정 31).
- 치지직에서 가져오지 않는 기능: 클립, 편성표, 라운지, e스포츠, 드롭스
- 카테고리는 가져온다. 잡담, 게임, 공부, 음악, 요리, 그림, 운동, 여행 8개로 고정하고, 홈에서 카테고리별로 방송을 묶어 보여준다(06 결정 31).

## 9. 심사 환경과 확인할 점

심사자는 맥북과 아이폰을 쓸 가능성이 높다. 브라우저는 크롬 계열로 예상한다.

- 맥 크롬에서 탭을 공유하면 탭 소리를 함께 보낼 수 있다. 공모 요구사항은 "탭 소리 또는 시스템 소리"라서 탭 소리만으로도 요구를 채운다.
- 맥에서 탭이 아니라 전체 화면을 공유하면 '화면 기록' 권한이 따로 필요하다. 권한을 켠 뒤에는 크롬을 다시 시작해야 한다.
- 아이폰의 크롬은 사파리와 같은 엔진을 쓴다. 그래서 아이폰에서는 사파리의 제약이 그대로 적용된다.
- 아이폰에서는 HTTPS 주소에서만 카메라와 마이크가 켜진다. 화면이 잠기거나 다른 앱으로 넘어가면 카메라가 끊긴다.
- 아이폰에서 영상이 자동으로 재생되려면 처음에는 소리가 꺼져 있어야 한다. 사용자가 한 번 눌러야 소리가 켜진다.

## 10. 확인되지 않은 가정

| 가정 | 확인 방법 |
|---|---|
| 장비 없는 사람이 준비 단계 때문에 방송을 포기한다 | 인터뷰나 사용 데이터로 확인해야 한다 |
| 가볍게 켠 사람이 반응과 수익을 얻으면 입문 스트리머가 된다 | 다시 방송하는 비율로 확인해야 한다 |
| 맥 크롬의 탭 공유는 화면 기록 권한 없이 동작한다 | 실제 맥북에서 테스트해야 한다 |
| 맥 크롬에서 시스템 소리 전체를 캡처할 수 있다 | 크롬과 macOS 버전별로 테스트해야 한다 |
| 치지직 모바일 앱에는 방송을 켜는 기능이 없다 | 실제 앱에서 확인해야 한다 |
