# 나비 운영 정책

- 마지막 수정: 2026-11-14
- 한 줄 요약: 라이브 방송 서비스 나비를 쓰는 회원, 방송자, 운영자가 지켜야 할 운영 정책을 한 문서에 모은 정책서다.
- 이 문서의 위치: [문서 색인](README.md)
- 기준 문서: 실제 동작은 [07 기능 명세](07-feature-spec.md)를, 그렇게 정한 이유는 [06 결정 기록](06-decisions.md)을 따른다. 약관 문장은 [09 방송자 이용약관](09-streamer-terms-draft.md)과 [10 이용약관](10-terms-of-service-draft.md)에 있다. 이 정책서와 원문이 다르면 원문을 따른다.
- 결정끼리 부딪히면 번호가 뒤인 결정을 따른다. 이 문서에는 최종 규칙만 적고, 바뀐 곳은 "바뀐 점"으로 짧게 밝힌다.
- 돈의 흐름(배분 비율, 환급 수수료, 정산)은 [11 수익 구조](11-business-model.md)에 있다. 이 문서에는 사용자가 지켜야 할 규칙만 한 줄씩 적는다.

## 1. 이 정책서를 읽는 법

2장부터 회원, 방송, 채팅, 후원, 신고, 방송자 활동 제한, 운영자 제재, 권한, 테스트 계정, 개인정보 순서로 적는다. 12장에는 아직 정하지 않은 것과 실제 운영 전에 바꿔야 할 것을 모았다. 각 장 끝의 "원문:" 줄은 근거가 되는 원문 절로 이어진다.

## 2. 회원 정책

| 항목 | 규칙 | 이유 |
|---|---|---|
| 가입 나이 | 만 14세 이상만 가입할 수 있다 | 이메일과 후원 기록을 모으므로 본인 동의가 필요하다 |
| 필수 동의 | 만 14세 이상 확인, 이용약관, 방송자 이용약관, 개인정보 수집과 이용에 모두 동의해야 가입 버튼이 눌린다. 서버도 동의 없는 가입을 거절한다 | 나비는 가입하면 누구나 바로 방송하고 후원을 받는다. 그래서 방송자 약관도 가입할 때 함께 받는다 |
| 동의 기록 | 동의한 항목, 약관 버전, 동의 시각을 저장한다 | - |
| 비밀번호 | 6자 이상이다. 가입할 때 "비밀번호 확인" 칸에 한 번 더 입력한다 | - |
| 로그인 없이 할 수 있는 일 | 방송 목록 보기, 시청, 다시보기, 채팅 읽기 | - |
| 로그인 오류 안내 | 이메일과 비밀번호 가운데 어느 쪽이 틀렸는지 알려주지 않는다 | - |

### 닉네임 규칙

| 항목 | 규칙 | 이유 |
|---|---|---|
| 길이와 글자 | 2~12자다. 한글, 영문, 숫자만 쓰고 띄어쓰기는 쓸 수 없다 | - |
| 중복 | 다른 사람과 같은 닉네임은 쓸 수 없다. 영문은 대소문자를 구분하지 않고 비교한다 | 채팅과 후원에서 누가 누구인지 헷갈리지 않게 한다 |
| 금칙어 | 금칙어가 들어간 닉네임은 쓸 수 없다. 채팅과 같은 금칙어 목록을 쓴다 | - |
| 변경 | 가입한 뒤 한 번만 바꿀 수 있다. 바꾸기 전에 확인 창으로 알린다 | 닉네임을 자주 바꾸면 누가 누구인지 알기 어렵다 |
| 바꾼 뒤 | 이미 남은 채팅과 후원 기록의 닉네임은 바꾸지 않는다. 바뀌기 전 닉네임은 다른 사람이 바로 쓸 수 없다 | 다른 사람이 같은 이름으로 과거 기록을 흉내 내지 못하게 한다 |
| 구글 가입 | 구글 계정 이름을 닉네임으로 그대로 쓰지 않는다. 직접 입력한다 | 구글 이름은 닉네임 규칙에 맞지 않는 경우가 많다 |

### 비밀번호 찾기

- 로그인 화면의 "비밀번호를 잊었어요"에서 이메일을 받고, 비밀번호를 다시 정하는 메일을 보낸다.
- 가입하지 않은 이메일을 넣어도 "메일을 보냈어요"로 똑같이 안내한다. 가입 여부를 알려주지 않기 위해서다.
- 구글로만 가입한 사람은 비밀번호가 없으므로 비밀번호 변경 메뉴를 보여주지 않는다.

### 탈퇴 조건과 탈퇴 뒤 처리

탈퇴할 때는 비밀번호를 한 번 더 받는다. 구글로 가입한 사람은 구글 로그인으로 한 번 더 확인한다. 아래 경우에는 탈퇴할 수 없다.

| 탈퇴할 수 없는 경우 | 이유 |
|---|---|
| 채팅 금지나 방송 금지가 적용 중이다 | 탈퇴하고 다시 가입해서 제재를 피하지 못하게 한다 |
| 방송 중인 방송이 있거나, 녹화가 녹화 중이거나 처리 중이다 | 방송과 녹화를 정리하기 전에 계정이 사라지면 주인 없는 파일이 남는다 |
| 내가 보낸 미션이 대기 중이거나 진행 중이다 | - |
| 결제 대기나 취소 중인 충전이 있다 | 탈퇴한 뒤 결제 결과가 오면 지운 사용자에게 꿀이 생긴다 |
| 환급 신청이 처리 중이다 | - |
| 테스트 계정이다 | 한 심사자가 지우면 다음 심사자가 쓸 수 없다 |

| 탈퇴 뒤 처리 | 규칙 |
|---|---|
| 지우는 것 | 계정, 내 방송, 다시보기 영상, 본인인증 정보, 정산 계좌 정보 |
| 남기는 것 | 내가 쓴 채팅은 남기고 닉네임을 "탈퇴한 사용자"로 바꾼다. 다른 사람의 대화 흐름이 끊기지 않게 하기 위해서다 |
| 돈이 오간 기록 | 충전, 후원, 정산, 환급 기록(계좌 끝 4자리와 예금주 포함)은 5년 동안 보관한다. 후원자 이름은 "탈퇴한 사용자"로 보여준다 |
| 남은 꿀 | 환급할 수 있는 꿀이 있으면 탈퇴 전에 환급 신청을 안내한다. 환급하지 않고 탈퇴하려면 남은 꿀을 포기한다는 데 따로 동의해야 한다. 포기한 꿀은 되살릴 수 없다 |
| 받지 못한 수익 배분금 | 방송자는 다음 지급일 뒤에 탈퇴할지, 남은 금액을 포기하고 바로 탈퇴할지 고른다. 포기에 동의한 시각은 운영 기록에 남는다 |
| 다시 가입 | 탈퇴한 이메일로 바로 다시 가입할 수 있다. 쓰던 닉네임도 다시 쓸 수 있게 풀어 준다 |

## 3. 방송 정책

### 누가 방송하나

- 가입한 회원은 누구나 바로 방송하고 후원을 받을 수 있다. 방송자 등록 단계를 따로 두지 않는다.
- 만 19세 미만도 방송하고 후원을 받을 수 있다. 만 19세 미만이 못 하는 것은 꿀 충전뿐이다(5장).
- 마이크 없이 방송을 시작하면 경고한 뒤 시작은 허용한다. 방송이 끝날 때까지 닫을 수 없는 안내를 보여준다. 방송자가 모르고 소리 없이 켜는 일을 막기 위해서다.
- 방송자는 관련 법과 운영정책을 어기는 콘텐츠를 내보내지 않는다. 다른 곳에서 돈을 받고 광고나 협찬을 하면 방송에 그 사실을 표시한다.
- 콘텐츠의 저작권은 방송자에게 있다. 나비는 나비 안에서 보여주고 다시보기로 저장하는 범위에서만 쓴다. 나비 밖(SNS 등)에 쓸 때는 방송자에게 먼저 묻는다.

### 방송 상태와 종료 규칙

방송 상태는 세 가지다. 준비는 방송을 만들었지만 아직 송출하지 않은 상태다. 방송 중은 송출하고 있는 상태다. 종료는 방송이 끝난 상태다.

| 항목 | 규칙 | 이유 |
|---|---|---|
| 방송 중으로 바뀌는 때 | "방송 시작"을 누른 뒤 영상이 실제로 올라와야 방송 중이 된다. 30초 안에 올라오지 않으면 준비 상태 그대로 두고 "방송을 시작하지 못했어요"를 보여준다. 30초는 임시값이다 | 연결 전에 탭을 닫으면 방송이 "방송 중"인 채로 남는 일을 막는다 |
| 끝나는 경로 | 종료 버튼, 화면 공유 중지, 송출 연결 끊김(탭 닫기, 새로고침, 네트워크 끊김, 휴대폰 잠금), 운영자의 강제 종료와 방송 금지 | 어떤 방법으로 끝나도 방송은 반드시 종료돼야 한다 |
| 되돌리기 | 종료된 방송은 다시 방송 중으로 돌아가지 않는다. 다시 방송하려면 새 방송을 만든다 | "끊기면 끝난다"를 분명하게 지킨다 |
| 송출 화면 다시 들어가기 | 방송 중인 방송의 송출 화면에는 다시 들어갈 수 없다. 송출 탭을 새로고침하거나 닫으면 방송이 끝난다. 나가기 전에 확인 창을 띄운다 | 함께 쓰는 테스트 계정에서 다른 사람이 진행 중인 방송을 가로채지 못하게 한다 |
| 네트워크가 잠깐 흔들릴 때 | 송출 연결이 스스로 다시 붙으면 방송이 이어진다 | 처음 받은 송출 권한을 그대로 쓰기 때문이다 |
| 종료 때 함께 정리하는 것 | 녹화를 처리 중으로 바꾸고, 대기 중 미션은 취소해 꿀을 돌려주고, 진행 중 미션은 실패로 처리한다 | 모든 종료 경로가 같은 서버 기능 하나를 거치므로 빠뜨리는 정리가 없다 |
| 홈에 오래 남은 준비 방송 | 준비 상태로 만든 지 1시간이 지난 방송은 홈에서 숨긴다. 내 방송 관리에는 남는다. 1시간은 임시값이다 | 만들고 나간 빈 방송이 홈을 채우지 않게 한다 |

### 삭제 규칙

| 항목 | 규칙 | 이유 |
|---|---|---|
| 방송 중 | 지울 수 없다. 삭제 버튼이 없고 서버도 거절한다 | 녹화와 후원은 방송이 끝나야 정리된다 |
| 준비 상태 | 지울 수 있다. 기다리던 시청자 연결도 함께 끊는다 | 아직 송출하지 않아서 남는 녹화가 없다 |
| 종료된 방송 | 지울 수 있다. 녹화가 처리 중이면 끝난 뒤에 지울 수 있다 | 늦게 온 녹화 완료 알림이 주인 없는 파일을 남기지 않게 한다 |
| 지울 때 함께 지우는 것 | 방송 정보, 채팅, 녹화 영상 | - |
| 후원 기록 | 지우지 않는다. 방송자의 "지운 방송" 묶음과 후원자의 내 후원 내역에 남는다 | 돈이 오간 기록이다 |

바뀐 점: 결정 7은 "녹화 중이거나 처리 중이면 지울 수 없다"였다. 결정 24에서 "방송 중이면 지울 수 없고, 녹화가 처리 중이면 지울 수 없다"로 바꿨다.

### 녹화와 공개 여부

| 항목 | 규칙 | 이유 |
|---|---|---|
| 녹화를 고르는 때 | 송출 화면에서 "방송 시작" 바로 위의 "이 방송 녹화하기" 스위치로 고른다. 기본은 꺼짐이다. 방송이 시작되면 바꿀 수 없다 | 녹화 여부는 방송을 켜는 순간에 정하는 것이 자연스럽다 |
| 녹화 시간 제한 | 한 번에 3분까지 녹화한다. 3분이 지나면 녹화만 멈추고 방송은 계속된다 | 무료 녹화 한도 안에서 운영해야 한다 |
| 한 달 제한 | 나비 전체의 이번 달 녹화가 50분을 넘으면 새 녹화를 시작하지 않는다. 녹화를 지워도 사용량은 줄지 않는다 | 한 사람이 무료 녹화를 다 쓰지 못하게 한다 |
| 녹화 실패 | 녹화가 실패해도 방송은 계속된다. 처리 중으로 30분이 지나면 실패로 본다 | 녹화 때문에 방송이 멈추면 안 된다 |
| 공개 여부 | 녹화는 처음에 비공개다. 방송자가 공개로 바꿔야 다시보기 목록에 나온다. 언제든 다시 비공개로 바꿀 수 있다 | 방송자가 보여주고 싶지 않은 장면이 녹화될 수 있다 |
| 비공개 녹화 | 방송자만 재생할 수 있다. 영상 주소는 30분만 쓸 수 있다. 비공개로 바꾸면 이미 받은 주소도 30분 안에 막힌다 | 영상 파일을 공개 주소로 두지 않는다 |
| 다시보기에서 할 수 없는 것 | 채팅 쓰기와 후원 | 끝난 방송과 같은 규칙이다(4장, 5장) |
| 보관 | 방송자는 자기 콘텐츠를 스스로 보관한다. 등급별 보관 기간은 추후 적용한다 | - |

3분, 50분, 30분은 임시값이다.

## 5. 후원·꿀 이용 정책

후원은 "꿀"로 한다. 꿀은 나비 안에서만 쓰는 후원용 포인트다. 꿀 1개는 1원이다. 배분 비율, 환급 수수료, 정산처럼 돈이 어떻게 나뉘는지는 [11 수익 구조](11-business-model.md)에 있다.

| 항목 | 규칙 | 이유 |
|---|---|---|
| 꿀의 성격 | 꿀은 나비가 파는 후원용 디지털 상품이다. 다른 사람에게 넘길 수 없다. 화면과 문서에서 "가상화폐"라고 부르지 않는다 | 꿀이 돈처럼 움직이면 상품으로 보기 어렵다 |
| 충전 자격 | 만 19세 이상만 충전할 수 있다. 처음 충전하기 전에 휴대폰 본인인증을 한 번 받는다. 이번 개발에서 본인인증은 테스트용 화면이다 | 미성년자가 부모 동의 없이 결제하면 나중에 취소될 수 있다. 나이를 확인하려면 본인인증이 필요하다 |
| 충전 동의 | 모든 충전 창에서 "꿀 충전과 후원 유의사항에 동의합니다"를 보여준다. 동의한 안내 버전과 시각을 저장한다 | 환급 수수료와 꿀 포기 규칙을 모르고 결제하는 일을 막는다 |
| 하루 충전 한도 | 한 계정은 하루(한국 시간 0시부터)에 100만 꿀까지 충전한다. 결제 대기 중인 충전도 한도에 넣고, 취소한 충전은 한도에서 빼지 않는다 | 업계 자율규제의 하루 100만 원 기준을 따른다. 결제창을 여러 개 열거나 충전과 취소를 되풀이해 한도를 넘지 못하게 한다 |
| 한 번에 후원 | 한 번에 100만 꿀까지 후원한다. 하루 후원 합계는 따로 세지 않는다 | 충전을 막으면 후원도 자연히 막힌다 |
| 충전 취소 | 충전하고 7일 안에 하나도 쓰지 않은 충전 건은 결제를 전액 취소할 수 있다. 자세한 조건은 [11 수익 구조](11-business-model.md)에 있다 | 쓰지 않은 결제는 돌려받을 수 있어야 한다 |
| 환급 신청 | 그 밖의 쓰지 않은 꿀은 신청하면 수수료를 떼고 본인 명의 계좌로 돌려준다. 금액 계산은 [11 수익 구조](11-business-model.md)에 있다 | 돈을 내고 산 잔액을 돌려주지 않으면 불공정 약관이 될 수 있다 |
| 내 방송 | 내 방송에는 후원할 수 없다 | - |
| 같은 명의 후원 | 후원자와 방송자의 본인인증 명의가 같으면 그 후원에 "같은 명의" 표시를 남긴다. 운영자는 정산 보류로 처리할 수 있다. 이 후원은 등급 승급에 필요한 후원 건수에서 뺀다 | 카드로 결제한 꿀을 자기 방송에 후원해 현금으로 바꾸는 행위는 법 위반이 될 수 있다 |
| 끝난 방송 | 종료된 방송과 다시보기에서는 후원할 수 없다. 버튼이 없고 서버도 거절한다 | 후원은 방송 중의 반응이다. 끝난 방송의 결제는 예외만 늘린다 |
| 결제 중 방송이 끝났을 때 | 충전만 하고 후원은 하지 않는다. 충전한 꿀은 내 꿀에 남는다 | 끝난 방송에는 후원하지 않는다는 규칙을 지킨다 |
| 로그인 | 로그인해야 후원한다 | - |

### 미션 후원

미션 후원은 시청자가 "이걸 해 주면 후원할게요"라고 요청하는 후원이다.

| 항목 | 규칙 | 이유 |
|---|---|---|
| 성격 | 대가가 아닌 응원이다. 방송자는 미션을 수행할 의무가 없고 거절할 수 있다 | 미션 후원이 방송자의 행동에 값을 치르는 것으로 보이지 않게 한다 |
| 금지 미션 | 위험한 행동, 불법 행위, 선정적인 행동, 다른 사람을 괴롭히는 행동을 요구하면 안 된다. 방송자도 이런 미션을 수락하거나 수행하지 않는다 | - |
| 금지 미션을 보낸 사람 | 사용자 신고(사유 "불법·위험한 행동")로 신고할 수 있다 | - |
| 미션 내용 | 1~50자다. 금칙어가 있으면 미션을 만들지 않는다 | - |
| 받는 때 | 방송 중에만 받는다. 준비 상태에서는 미션을 보낼 수 없다. 채팅 후원은 준비 상태에서도 받는다 | 준비 상태 방송은 시작하지 않은 채 남거나 지워질 수 있다. 그러면 미션에 묶인 꿀을 정리할 길이 없다 |
| 방송이 끝날 때 | 대기 중 미션은 취소하고 꿀을 모두 돌려준다. 진행 중 미션은 실패로 처리한다 | 묶인 꿀이 남지 않게 한다 |

## 7. 방송자 활동 제한

방송자는 자기 방송에서 특정 시청자의 채팅을 막을 수 있다. 입문 방송자가 운영자를 기다리지 않고 악성 시청자를 스스로 막게 하기 위해서다. 운영자 제재(8장)와는 따로 동작한다.

| 항목 | 규칙 |
|---|---|
| 거는 곳 | 송출 화면 채팅에서 닉네임을 누르면 나오는 "이 방송에서 채팅 금지" |
| 기간 | 1일, 7일, 영구 가운데 고른다. 메모를 0~100자로 남길 수 있다 |
| 효과 | 그 방송자의 모든 방송에서 채팅과 후원 메시지를 쓸 수 없다. 입력 칸에 "이 방송에서 채팅이 제한됐어요"를 보여준다 |
| 그래도 할 수 있는 것 | 시청, 후원, 신고는 할 수 있다. 다른 방송자의 방송에서는 채팅도 할 수 있다 |
| 걸 수 없는 대상 | 방송자 자신, 운영자, 익명 후원자 |
| 풀기 | 내 방송 관리의 "활동 제한" 탭에서 언제든 "해제"로 푼다 |
| 기간이 끝나는 처리 | 채팅을 쓸 때마다 서버가 끝나는 시각을 확인한다. 끝났으면 바로 채팅을 받는다. 정해진 시각에 도는 작업은 쓰지 않는다 |

## 8. 운영자 제재 정책

### 제재 종류와 기간

위반 정도에 따라 단계를 건너뛸 수 있다.

| 제재 | 기간 | 효과 |
|---|---|---|
| 경고 | 없음 | 다음 로그인 때 경고 안내를 한 번 보여준다. 이용 제한은 없다 |
| 채팅 금지 | 1일 또는 7일 | 모든 방송에서 채팅과 후원 메시지를 쓸 수 없다. 시청과 후원은 할 수 있다 |
| 방송 금지 | 7일 또는 30일 | 방송을 만들거나 시작할 수 없다. 방송 중이면 바로 끝낸다. 그 방송자의 방송 주소에는 "운영정책 위반으로 일시적으로 방송할 수 없어요"가 모든 시청자에게 보인다 |
| 영구 정지 | 없음 | 로그인할 수 없다. 방송 중이면 끝낸다. 그 방송자의 정산을 보류한다. 영구 정지를 풀어도 정산 보류는 따로 풀어야 한다 |

- 제재와 별도로 운영자는 채팅 숨기기, 방송 강제 종료, 종료된 방송의 다시보기 비공개 전환을 할 수 있다. 이때도 사유는 필수다.
- 같은 종류의 제재가 겹치면 더 늦게 끝나는 쪽을 따른다.
- 기간이 끝나는 처리는 요청이 올 때마다 서버가 끝나는 시각을 확인한다.
- 운영자는 적용 중인 제재를 언제든 해제할 수 있다. 해제할 때도 사유를 적는다.
- 운영자에게는 제재를 걸 수 없다.
- 영구 정지를 받으면 방송자 계약을 끝낼 수 있다. 이때는 고칠 기간을 두지 않는다.

### 신고 묶음 처리

| 항목 | 규칙 | 이유 |
|---|---|---|
| 묶는 기준 | 신고를 대상 사용자별로 묶는다. 채팅 신고와 사용자 신고는 그 사용자로, 방송 신고는 그 방송자로 묶는다 | 한 사람에게 쌓인 신고를 한 번에 판단한다 |
| 조치 방법 | 제재하기, 콘텐츠만 숨기기, 기각 세 가지다 | 위반 정도에 따라 고른다 |
| 처리 결과 | 상세에서 조치하면 그 사용자에게 걸린 접수 상태의 신고가 모두 같은 결과가 된다 | 같은 사람에 대한 신고를 따로따로 처리하지 않는다 |
| 사유 | 모든 조치에 사유가 필수다. 사유는 운영 기록과 제재 기록에 남는다 | 나중에 조치의 근거를 확인할 수 있어야 한다 |

### 이의 제기

- 경고, 채팅 금지, 방송 금지에 한 번씩 이의를 제기할 수 있다. 내용은 10~500자로 적는다.
- 영구 정지는 로그인할 수 없으므로 화면 안에서 이의를 제기할 수 없다. 로그인 화면에 보이는 이메일 주소로 제기한다.
- 운영자가 받아들이면 제재를 "이의로 취소"로 바꾸고 효과를 바로 푼다. 거절하면 답변을 적는다.
- 이의를 제기하는 동안에도 제재는 계속 적용된다.

### 운영 기록

- 운영자의 모든 조치를 기록한다. 제재, 해제, 신고 처리, 이의 제기 처리, 강제 종료, 정산 보류와 해제, 정산 실행, 환급 승인과 거절, 금칙어 변경, 테스트 계정 초기화가 모두 들어간다.
- 운영자, 행동, 대상, 사유, 바뀌기 전과 뒤의 값, 시각을 남긴다.
- 운영 기록은 서버만 쓴다. 아무도 고치거나 지울 수 없다. 운영자의 권한 남용을 나중에 확인하기 위해서다.
- 운영자 권한은 서버 스크립트로만 준다. 화면에서는 아무도 운영자를 만들 수 없다.

| 영구 정지 | 정지된 사람 | 로그인 화면에 "운영정책 위반으로 이용이 정지된 계정이에요"와 이의 제기 이메일 주소를 보여준다 |

## 10. 심사용 테스트 계정 정책

로그인 화면에는 비밀번호 없이 들어가는 "테스트 방송자", "테스트 시청자", "테스트 운영자" 버튼이 있다. 배포 주소를 아는 사람은 누구나 누를 수 있다. 그래서 아래 규칙으로 실제 사용자와 다음 심사자를 지킨다. "심사용 계정"은 심사를 위해 스크립트로 미리 만들어 둔 계정이다.

| 항목 | 규칙 | 이유 |
|---|---|---|
| 테스트 운영자가 조치할 수 있는 대상 | 심사용 계정과 그 계정의 방송, 채팅, 정산, 환급뿐이다 | 테스트 운영자가 실제 가입자를 정지하거나 정산을 보류하면 안 된다 |
| 실제 가입자 | 테스트 운영자는 조회도 할 수 없다. 목록에는 "심사용이 아닌 계정"으로 보이고 닉네임, 이메일, 본인인증 이름, 계좌, 충전·후원 기록을 가린다. 조치를 누르면 "테스트 운영자는 심사용 계정만 보고 조치할 수 있어요"를 보여주고 서버도 거절한다 | 누구나 테스트 운영자로 들어올 수 있으므로 개인정보를 보여주면 안 된다 |
| 실제 가입자가 심사용 방송에 쓴 채팅 | 테스트 운영자가 숨길 수 있다. 작성자 제재는 할 수 없다 | 채팅은 심사용 방송에 속하지만 작성자는 실제 사용자다 |
| 테스트 계정 제재 | 테스트 운영자는 테스트 방송자, 테스트 시청자, 샘플 계정을 제재하거나 정산 보류할 수 없다. 실제 운영자는 할 수 있다 | 한 심사자가 정지하면 다음 심사자가 쓸 수 없다. 실제 운영자는 공개 계정으로 하는 나쁜 방송을 막아야 한다 |
| 제재 연습 | 제재는 신고가 쌓여 있는 "제재 연습용 계정"으로 확인한다. 로그인 정보는 루트 README에 있다 | 심사자가 제재 흐름을 끝까지 해 볼 수 있다 |
| 초기화 | 테스트 운영자는 심사용 계정을 처음 상태로 되돌릴 수 있다. 전체 초기화는 10분에 한 번만 된다 | 전체 초기화를 되풀이하면 다른 심사자가 보던 화면이 사라진다 |
| 금칙어 | 테스트 운영자는 금칙어 목록을 보기만 한다 | 누가 금칙어를 지우면 채팅 걸러내기가 꺼진다 |
| 테스트 방송 길이 | 테스트 방송자의 방송은 30분까지다. 25분에 "5분 뒤에 방송이 끝나요"를 보여주고 30분에 끝낸다 | 공개 계정으로 무료 송출 사용량을 다 쓰지 못하게 한다 |
| 버튼 로그인 횟수 | 같은 IP에서 1시간에 20번까지 들어갈 수 있다. 넘으면 "잠시 뒤에 다시 시도해 주세요"를 보여준다 | 버튼은 배포 주소를 아는 누구나 누를 수 있다 |
| 닉네임 변경과 탈퇴 | 테스트 계정은 할 수 없다 | 다음 심사자가 같은 계정을 써야 한다 |
| 심사가 끝난 뒤 | 버튼 로그인 기능을 끈다. 끄는 날짜는 루트 README에 적는다 | - |

바뀐 점: 결정 13은 테스트 방송자와 테스트 시청자를 누구도 제재할 수 없게 했다. 결정 29에서 이 보호를 테스트 운영자에게만 적용하도록 좁혔다. 결정 23은 테스트 운영자가 실제 가입자를 조회할 수 있고 금칙어도 바꿀 수 있게 했다. 결정 25에서 조회와 금칙어 변경을 모두 막았다.

30분, 20번, 10분은 임시값이다.

## 11. 개인정보

- 나비가 모으는 정보는 이메일, 닉네임, 충전과 후원 기록, 본인인증 정보(이름, 생년월일, 명의 확인값), 환급·정산 계좌(은행 이름, 계좌번호 끝 4자리, 예금주)다.
- 전체 계좌번호와 휴대폰 번호는 저장하지 않는다.
- 명의 확인값은 이름, 생년월일, 휴대폰 번호를 합쳐 해시한 값이다. 해시는 원래 값을 알아볼 수 없게 바꾸는 계산이다. 같은 사람이 충전한 꿀로 자기 방송에 후원하는지 확인하는 데도 쓴다.
- 자세한 내용은 개인정보 처리방침을 따른다.
- 탈퇴한 뒤 무엇을 지우고 무엇을 남기는지는 2장의 "탈퇴 뒤 처리"에 있다.

## 12. 아직 정하지 않은 것과 실제 운영 전에 바꿔야 할 것

### 임시값

- 채팅 도배 제한 1초, 하루 신고 한도 20건, 방송 시작 실패로 보는 시간 30초, 홈에서 준비 방송을 숨기는 시간 1시간

- 테스트 방송자의 방송 길이 30분, 같은 IP의 1시간 버튼 로그인 20번, 테스트 운영자의 전체 초기화 간격 10분
- 알림을 보여주는 기간 30일, 포인트 이름 "꿀"
- 모두 개발과 심사를 위해 임시로 정한 값이다. 실제 운영 전에 다시 정한다.

### 실제 운영 전에 바꾸거나 확인할 것

| 항목 | 지금 상태 | 바꿔야 할 것 |
|---|---|---|
| 약관 | 09, 10 약관은 법률 검토를 받지 않은 초안이다. 영구 정지 이의 제기 이메일 주소도 아직 비어 있다 | 법률 검토를 받고 이메일 주소를 정한다 |
| 본인인증 | 이름, 생년월일, 휴대폰 번호만 넣으면 인증된 것으로 처리하는 테스트 화면이다 | 인증 업체와 계약해 실제 본인인증을 붙인다 |
| 하루 충전 한도 | 계정 단위로 센다. 한 사람이 계정을 여러 개 만들면 넘길 수 있다 | 본인인증 명의 단위로 센다 |
| 같은 명의 후원 | 방송자가 충전한 적이 없으면 같은 명의를 찾지 못한다 | 정산 정보를 등록할 때 본인인증을 받는다 |
| 꿀의 법적 성격 | 꿀이 선불전자지급수단인지, 미션 후원을 대가로 볼지 공식 판단을 찾지 못했다 | 금융위원회에 묻거나 변호사 의견을 받는다 |
| 금칙어 목록 | 공개된 목록의 이용 조건을 확인하지 않았다 | 출처를 정하거나 직접 50~100개로 시작한다 |
| 기록 삭제 | 5년이 지난 돈 기록을 지우는 작업, 30일이 지난 알림을 지우는 작업, 탈퇴가 중간에 멈췄을 때 다시 실행하는 작업을 이번 개발에서 만들지 않았다 | 실제 운영 전에 이 작업들을 만든다 |
| 송출 화면 다시 들어가기 | 방송 중에는 막는다. PC에서 실수로 새로고침해도 방송이 끝난다 | 같은 브라우저에서만 다시 들어가게 허용하는 방식을 다음 단계로 검토한다 |
| 다시보기 보관 기간 | 등급별 보관 기간은 "추후 적용"이다 | 등급별 기간을 정한다 |
| 테스트 계정 | 공개 버튼 로그인이 켜져 있다 | 심사가 끝나면 끈다 |
| 공모 기간 정산 | 결제와 정산은 시연용이다. 심사용이 아닌 방송자는 수익 배분금을 받을 수 없다 | 정산 정보 등록 화면을 만들고 실제 송금을 붙인다 |
